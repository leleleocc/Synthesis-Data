Build Redis 7.2.16 from the tree at `/app` with OpenSSL TLS linked into both the server and the CLI, following `/app/TLS.md` (`BUILD_TLS=yes`). Leave working binaries at `/app/src/redis-server` and `/app/src/redis-cli`. PEM material for this job is already under `/data/tls/` (`ca.crt`, `ca.key`, `redis.crt`, `redis.key`, `server.crt`, `server.key`, `client.crt`, `client.key`). Do not modify anything under `/data`.

Write `/app/master.conf` and `/app/replica.conf` and start two long-lived `redis-server` processes that are still running when you stop. The master must bind `127.0.0.1`, keep `protected-mode yes`, disable plain TCP with `port 0`, listen on `tls-port 6379`, use `/data/tls/redis.crt`, `/data/tls/redis.key`, and `/data/tls/ca.crt`, set `tls-auth-clients no` and `tls-replication yes`, use `daemonize no`, `dir /results/master`, `dbfilename dump.rdb`, `pidfile /results/master.pid`, and `logfile /results/master.log`. The replica must bind `127.0.0.1`, keep `protected-mode yes`, use `daemonize no`, use the same TLS files and `tls-replication yes` / `tls-auth-clients no`, disable plain TCP with `port 0`, listen on `tls-port 6380`, replicate from `127.0.0.1` port `6379`, stay `replica-read-only yes`, and use `dir /results/replica`, `dbfilename dump.rdb`, `pidfile /results/replica.pid`, and `logfile /results/replica.log`. Create those `dir` paths before starting the processes.

The replica must finish initial sync over TLS (not plaintext). After both instances are up, set key `tls:probe` to `ok` on the master through a TLS client connection; the replica must be able to serve that key over TLS as well. Plain TCP clients to 6379 and 6380 must not succeed.

Write `/results/tls-report.json` as a single UTF-8 JSON object with no BOM, Unix newlines, and a trailing newline. Use exactly these keys in this order: `redis_version`, `master_tcp_port`, `master_tls_port`, `replica_role`, `master_link_status`, `tls_probe`. Set `redis_version` to the string `7.2.16`, `master_tcp_port` to the integer `0`, `master_tls_port` to the integer `6379`, `replica_role` to the string `slave`, `master_link_status` to the string `up`, and `tls_probe` to the string `ok`.
