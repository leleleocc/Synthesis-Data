Configure this Redis tree as a local LRU cache from `/app/redis.conf`. The running `/app/src/redis-server` must listen only on `127.0.0.1:6379`, keep `protected-mode yes`, cap memory at `67108864` bytes, evict with `allkeys-lru`, disable RDB snapshots (`save` empty) and AOF, use `dir /data`, `pidfile /results/redis.pid`, `logfile /results/redis.log`, `unixsocket /results/redis.sock`, and `unixsocketperm 700`. Keep `daemonize no` and leave the process running. Persist the same settings with `CONFIG REWRITE` so `/app/redis.conf` still shows them after a restart would.

The cache policy must actually evict: after start, filling keys until `maxmemory` is hit must make `INFO stats` `evicted_keys` at least 1, while `GET cache:warmup` still works if you set that key first. Do not bind `0.0.0.0` or an IPv6 wildcard.

Write `/results/cache_config.env` as ASCII `KEY=value` lines with a trailing newline and keys in this order: `BIND`, `PORT`, `PROTECTED_MODE`, `MAXMEMORY`, `MAXMEMORY_POLICY`, `SAVE`, `APPENDONLY`, `DIR`, `PIDFILE`, `UNIXSOCKET`, `EVICTED_KEYS`. Values must match live `CONFIG GET` for `bind`, `port`, `protected-mode`, `maxmemory`, `maxmemory-policy`, `save`, `appendonly`, `dir`, `pidfile`, and `unixsocket`; `EVICTED_KEYS` must be the integer `evicted_keys` from `INFO stats`. `/results/redis.pid` must hold the live PID whose `/proc/<pid>/exe` is `/app/src/redis-server`.
