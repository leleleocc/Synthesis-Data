# 构造一份有模型区分度的 Harbor task

你有且只有一个 construction life：构造 `/app/build/task/` 里的真实 Harbor task，而不是完成
它当前 instruction；保持原任务的领域和核心目标，并交付整个 `/app/build/`。

现在读取并持续遵循 `/app/method/sop.md`。这是环境内可重复读取的唯一执行手册；开局没有可复用的
旧 workspace，SOP 负责发现任何 compact previous-life reference。无人交互时保持 solo、自主推进到
SOP 的交付条件，除非外部中断或工具持续不可用。
