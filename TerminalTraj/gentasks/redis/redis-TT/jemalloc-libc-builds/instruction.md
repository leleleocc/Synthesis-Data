The platform team needs two Redis 7.2.16 builds from `/app` side by side: the default Linux allocator (jemalloc as selected by `/app/src/Makefile`) and a `MALLOC=libc` build. Compile both from this tree. Install the jemalloc server binary at `/results/bin/jemalloc/redis-server` and its CLI at `/results/bin/jemalloc/redis-cli`. Install the libc server at `/results/bin/libc/redis-server` and its CLI at `/results/bin/libc/redis-cli`. Each binary must be a real ELF executable produced by this source tree (not a wrapper script).

Write `/results/jemalloc.conf` and `/results/libc.conf`. Both bind `127.0.0.1`, use `protected-mode yes`, `daemonize no`, `save ""`, and `appendonly no`. The jemalloc instance uses `port 6379`, `dir /results/jemalloc-data`, `pidfile /results/jemalloc.pid`, `logfile /results/jemalloc.log`, `activedefrag yes`, `active-defrag-ignore-bytes 1048576`, `active-defrag-threshold-lower 10`, and `active-defrag-threshold-upper 100`. The libc instance uses `port 6380`, `dir /results/libc-data`, `pidfile /results/libc.pid`, and `logfile /results/libc.log`, and must not enable `activedefrag` in the file (that build cannot turn it on). Create the data directories and leave both servers running.

`INFO memory` on the jemalloc process must report an allocator name that starts with `jemalloc` and `active_defrag_running` as an integer field. `INFO memory` on the libc process must report `mem_allocator:libc`. `CONFIG SET activedefrag yes` against the libc process must fail with Redis's allocator error (do not copy an invented message). `CONFIG GET activedefrag` on the jemalloc process must return `yes`.

Write `/results/alloc-report.json` as a single UTF-8 JSON object with no BOM, Unix newlines, and a trailing newline. Use exactly these keys in this order: `jemalloc_allocator_prefix`, `libc_allocator`, `jemalloc_activedefrag`, `libc_activedefrag_set_ok`. Set `jemalloc_allocator_prefix` to the string `jemalloc`, `libc_allocator` to the string `libc`, `jemalloc_activedefrag` to the string `yes`, and `libc_activedefrag_set_ok` to boolean `false`.
