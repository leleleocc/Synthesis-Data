Package llama.cpp as a relocatable CPU-only CMake install that a downstream project can consume with `find_package(Llama)`. From `/app`, configure, build, and install into `/results/llama-prefix`. Use a Release CPU build with shared libraries, no CUDA, Metal, Vulkan, or BLAS, and with tests, examples, tools, server, and the unified app disabled, and OpenSSL disabled. Do not modify files under `/data`.

After install, `/results/llama-prefix` must contain `include/llama.h`, `include/ggml.h`, `include/gguf.h`, the llama and ggml shared libraries under `lib` or `lib/x86_64-linux-gnu`, and CMake package files such that `find_package(Llama REQUIRED)` succeeds when `CMAKE_PREFIX_PATH` is `/results/llama-prefix`. Create a consumer under `/results/src/probe` that uses `find_package` the way `/app/examples/simple-cmake-pkg` and `/app/cmake/llama-config.cmake.in` describe. Install the consumer binary to `/results/bin/llama-probe`.

`/results/bin/llama-probe` takes no arguments. It must load the CPU backend, write `/results/probe.json` (UTF-8, newline at EOF) with keys in this order: `n_backend` (int, `ggml_backend_reg_count()` after the CPU backend is registered), `has_cpu` (bool, true if `ggml_backend_cpu_init` returns non-null), `ggml_type_count` (int, `GGML_TYPE_COUNT` from `ggml.h`), `qk4_0` (int, `ggml_blck_size(GGML_TYPE_Q4_0)`), `qk8_0` (int, `ggml_blck_size(GGML_TYPE_Q8_0)`), `qnt_version` (int, `GGML_QNT_VERSION`). JSON booleans are `true`/`false`. Exit 0. Leave the prefix tree and the probe binary in place.
