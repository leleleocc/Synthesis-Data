Audit ggml's CPU quantizers on the synthetic F32 tensors under `/data/tensors`. Each `*.f32` file is a little-endian float32 buffer. A sibling `*.shape` UTF-8 text file lists one integer per line, which are the ggml `ne[]` dimensions with `ne[0]` first. Do not modify files under `/data`.

Build `/results/bin/quant-audit` against ggml in `/app` that, for each tensor, quantizes the packed F32 buffer with `ggml_quantize_chunk` for types `Q8_0`, `Q4_0`, `Q5_0`, and `Q4_K` (in that order), then dequantizes with the type's `to_float` from `ggml_get_type_traits`. Write packed bytes to `/results/packed/<stem>.<type>` using lower-case type names with underscores (`q8_0`, `q4_0`, `q5_0`, `q4_k`). Write `/results/quant_audit.json` as UTF-8 JSON with keys in this order: `tensors` (array sorted by `stem`; each object has `stem`, `ne` (array of exactly 4 ints, unused dims 1), `n_elem` (int), `types` (array of `{type, nbytes, nbytes_expected, rmse, requires_imatrix}` in the type order above; `type` is one of `Q8_0`, `Q4_0`, `Q5_0`, `Q4_K`)). `nbytes_expected` must equal `ggml_row_size(type, ne[0]) * (n_elem / ne[0])`. `rmse` is `sqrt(mean((x-xhat)^2))` with 10 digits after the decimal. `requires_imatrix` is the bool from `ggml_quantize_requires_imatrix`. End the file with a newline.

Run with a single thread. None of the four types requires an importance matrix; pass a null imatrix. Leave `/results/bin/quant-audit` runnable as `quant-audit --tensors-dir DIR --out-json PATH --packed-dir DIR` (exit 0 on success).
