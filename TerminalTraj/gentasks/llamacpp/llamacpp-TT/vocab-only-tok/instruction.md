Create a vocab-only GGUF for a tiny SentencePiece-style tokenizer and a CLI that tokenizes with libllama. The vocabulary description is `/data/spm_vocab.json`. Write `/results/tiny-vocab.gguf` and `/results/tokens.jsonl`. Do not modify files under `/data`.

`/data/spm_vocab.json` is UTF-8 JSON with keys `architecture` (string), `tokenizer_model` (string), `tokens` (array of strings), `scores` (array of floats, same length), `token_types` (array of ints, `llama_token_type` values), `bos_id`, `eos_id`, `unk_id`, `add_bos` (bool), `add_eos` (bool), and `add_space_prefix` (bool). The GGUF must be version 3, little-endian, and loadable by `llama_model_load_from_file` with `llama_model_params.vocab_only` set true. Set `general.architecture` from `architecture`, `tokenizer.ggml.model` from `tokenizer_model`, `tokenizer.ggml.tokens`, `tokenizer.ggml.scores`, `tokenizer.ggml.token_type`, and the special-id / add-flag keys the loader in `/app/src/llama-vocab.cpp` reads (`tokenizer.ggml.bos_token_id`, `tokenizer.ggml.eos_token_id`, `tokenizer.ggml.unknown_token_id`, `tokenizer.ggml.add_bos_token`, `tokenizer.ggml.add_eos_token`, `tokenizer.ggml.add_space_prefix`). Include no weight tensors.

Build llama.cpp from `/app` as a CPU Release library and leave `/results/bin/tok-cli`. It must load the GGUF with `vocab_only`, tokenize each non-empty line of `/data/prompts.txt` (UTF-8, newline-delimited) with `llama_tokenize` using `add_special=true` and `parse_special=true`, and append one JSON object per line to `/results/tokens.jsonl` with keys in this order: `line` (int, 1-based index in the prompts file including blank lines that were skipped), `text` (the prompt line without the trailing newline), `n_tokens` (int), `tokens` (array of ints), `detok` (string from `llama_detokenize` with `remove_special=false` and `unparse_special=true`). JSONL is UTF-8, one object per line, newline at EOF. `/results/bin/tok-cli --model PATH --prompts PATH --out PATH` exits 0.
