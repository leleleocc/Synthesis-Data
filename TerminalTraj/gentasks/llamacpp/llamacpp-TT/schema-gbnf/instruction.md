The serving stack needs JSON Schema compiled to GBNF with llama.cpp's in-tree converter, plus a grammar sanity check before those grammars are attached to a sampler. Using sources under `/app`, build `/results/bin/schema-gbnf` that takes one positional schema path argument and writes a GBNF grammar to stdout. Link it against the `json_schema_to_grammar` implementation in `/app/common/json-schema-to-grammar.cpp` (not a reimplementation). Do not modify files under `/data`.

Convert every top-level `*.json` file in `/data/schemas` to `/results/grammars/<stem>.gbnf` with that binary. Each grammar must define a `root` rule and must be accepted by llama.cpp's GBNF parser (`llama_grammar_parser` in `/app/src/llama-grammar.h`). Write `/results/grammar_report.json` as UTF-8 JSON with keys in this order: `schemas` (array of objects sorted by `file`; each object has `file` (basename), `stem`, `n_bytes` (grammar file size in bytes), `has_root` (bool), `parse_ok` (bool)), `n_ok` (int, count of entries with `parse_ok` true). End the file with a newline.

Also build `/results/bin/gbnf-check` that takes one positional `.gbnf` path, exits 0 if the grammar parses and defines `root`, and exits 1 otherwise. Schemas include integer `minimum`/`maximum`, string enums, `additionalProperties`, `anyOf`, and internal `$ref` fragments; follow the converter already in the tree. Leave both binaries in place.
