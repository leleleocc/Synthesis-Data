A downstream kernel team needs a CPU-only ggml reference for a tiny scaled-dot-product attention block so later GPU ports have a bit-reproducible baseline. Using the llama.cpp / ggml sources in `/app`, build a program that reads `/data/attn_fixture.json` and writes `/results/attn_out.bin` plus `/results/attn_meta.json`. Do not modify files under `/data`.

The fixture is UTF-8 JSON with keys `n_head` (int), `n_embd_head` (int), `n_token` (int), `eps` (float), `rope_freq_base` (float), `q`, `k`, `v`, and `pos`. Arrays `q`, `k`, and `v` are nested lists of floats indexed `[n_token][n_head][n_embd_head]`. `pos` is a length-`n_token` list of int32 positions. Implement the compute graph with ggml. RMSNorm each of Q, K, and V independently along the head-dimension axis (`n_embd_head`) with the given `eps` and no learned scale (`ggml_rms_norm`). Apply `ggml_rope_ext` to the normalized Q and K with `n_dims` equal to `n_embd_head`, `mode` 0 (`GGML_ROPE_TYPE_NORMAL`), `n_ctx_orig` 0, `freq_base` from the fixture, `freq_scale` 1.0, `ext_factor` 0.0, `attn_factor` 1.0, `beta_fast` 32.0, `beta_slow` 1.0, positions tensor `b` equal to fixture `pos` as int32, and frequency-factor tensor `c` NULL. Then run scaled-dot-product attention independently per head: scores = (Q K^T) * (1/sqrt(n_embd_head)), causal F32 mask (0 on allowed key positions `<=` the query position, `-inf` on future keys) passed as the `mask` argument of `ggml_soft_max_ext` with `scale` 1.0 and `max_bias` 0.0 over keys, then mix with V. Use the CPU backend with one thread. Write the output as little-endian float32 to `/results/attn_out.bin` with no header, packed in C order as `[n_token][n_head][n_embd_head]` (same indexing as the fixture arrays).

Write `/results/attn_meta.json` as a single UTF-8 JSON object with keys in this order: `n_head` (int), `n_embd_head` (int), `n_token` (int), `n_bytes` (int, byte size of `attn_out.bin`), `rms_q` (RMS of RMSNorm(Q) over all elements, JSON number with exactly 8 digits after the decimal), `max_attn` (maximum element of the softmax tensor over all heads, query positions, and key positions, JSON number with exactly 8 digits after the decimal). End the file with a newline. Leave the runnable binary at `/results/bin/attn_ref`. It must accept `--fixture PATH --out PATH --meta PATH` and exit 0 on success.
