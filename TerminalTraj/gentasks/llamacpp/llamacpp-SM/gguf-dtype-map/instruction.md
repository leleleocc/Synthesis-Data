Write `/results/gguf_dtype_map.py` (Python 3, stdlib only, executable bit set) and `/results/dtype_table.json`. The script is invoked as `python3 /results/gguf_dtype_map.py --ftype <NAME> --tensor <name>` where `<NAME>` is a `llama_ftype` enumerator without the `LLAMA_FTYPE_` prefix (for example `MOSTLY_Q8_0`). It must print a single ggml type name (the `GGML_TYPE_*` suffix, such as `Q8_0` or `F16`) followed by a newline and no other output. Exit 2 if the ftype name is unknown. Implement the same default ftype-to-tensor mapping as `prepare_tensors` in `/app/conversion/base.py` for `ALL_F32`, `MOSTLY_F16`, `MOSTLY_BF16`, `MOSTLY_Q8_0`, `MOSTLY_TQ1_0`, and `MOSTLY_TQ2_0`, including the overrides that force F32 for non-`.weight` tensors (and other name-based F32 forces in that function) and the TOKEN_EMBD / PER_LAYER_TOKEN_EMBD / OUTPUT special case that stays F16 under the ternary file types. Names `token_embd.weight`, `per_layer_token_embd.weight`, and `output.weight` are those vocab/output tensors. Treat tensors as 2-D weights unless the name itself selects an override in `prepare_tensors`. A tensor whose name is `tokenizer.ggml.tokens` or starts with `tokenizer.ggml.` is not a model weight: print `NA` and exit 0.

`/results/dtype_table.json` is UTF-8 JSON with a trailing newline: an array of objects with keys in this order: `ftype` (string enum name without the `LLAMA_FTYPE_` prefix), `tensor` (string), `ggml_type` (string, same spelling the script prints). Include every combination of those six ftypes with the tensor names listed one per line in `/data/tensor_names.txt` (UTF-8, no comments, no blank lines). Emit rows in ftype order as listed above; within each ftype, emit tensors in `/data/tensor_names.txt` order. Do not modify files under `/data`. Do not require torch or network.
